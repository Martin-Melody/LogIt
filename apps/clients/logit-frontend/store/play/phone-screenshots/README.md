# Phone screenshots

Play needs 2–8, long edge 1080–3840px, 16:9 or 9:16.

Capture these on a real device (best quality) with some real training/nutrition
data logged, covering: home, splits, active session, history, progress charts,
nutrition diary, habits.

`../../../scripts/capture-screenshots.mjs` produces rough placeholders from the
dev server (`npm run dev -- --port 5199`) but they show empty states and the
onboarding tour bubbles — fine for a first pass, not for the final listing.
