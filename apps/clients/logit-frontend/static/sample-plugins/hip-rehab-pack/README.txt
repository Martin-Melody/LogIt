Hip Rehab Pack — a sample mobility-pack (content plugin, pure data).

Eight hip prehab / rehab drills — banded hip flexion, clamshells, 90/90 lift-offs,
adductor rock-backs — added straight to your Mobility-block drill catalogue with
their default metric (hold vs reps), per-side flag and coaching cues.

No code runs. The file is fetched once, hash-verified against the manifest's
`integrity`, parsed, and the parsed result is stored locally.
